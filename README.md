# Flex Dev — Code source complet

Ces fichiers sont ceux de la version publiée du site, sans modification du design.
Version 1 — commit 1d5ec47abb59794424a097adb270ebcbf6ebf121

## Ouvrir dans VS Code
1. Décompressez le ZIP (clic droit → Extraire tout sous Windows).
2. Dans VS Code : Fichier → Ouvrir un dossier → choisissez le dossier flex-dev.
3. Ouvrez dist/index.html pour accéder au HTML.
4. Les styles sont dans dist/style.css et le JavaScript dans dist/script.js.
5. Pour afficher le site, ouvrez dist/index.html dans votre navigateur depuis l'explorateur de fichiers. Vous pouvez aussi utiliser Live Server dans VS Code.

## Fichiers
- dist/index.html : page complète.
- dist/style.css : styles et mise en page responsive.
- dist/script.js : interactions du menu mobile.
- dist/favicon.svg : icône du site.
- .openai/hosting.json : configuration d'hébergement Sites d'origine.

Ce site est statique : aucune installation npm, aucun serveur backend et aucune compilation ne sont nécessaires. Le dossier dist contient directement les sources utilisées par le site publié.

Les images sont chargées depuis Unsplash et les polices depuis Google Fonts : une connexion Internet est nécessaire pour les afficher comme sur le site publié. Les liens externes, notamment celui du contact, sont conservés à l'identique.

L'historique Git et les identifiants temporaires d'accès au dépôt ne sont pas inclus.
